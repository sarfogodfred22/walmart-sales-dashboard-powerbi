# Walmart Sales Overview - Store Performance (2010-2012)

Power BI dashboard analyzing Walmart's sales performance across 45 stores from 2010-2012.

![Dashboard Page 1](Walmart_Sales_Dashboard.PNG%201.PNG)
![Dashboard Page 2](Walmart_Sales_Dashboard.PNG%202.PNG)

### 📊 Key KPIs
- **Total Sales:** 6.74bn
- **Avg Weekly Sales:** 1.05M
- **Number of Stores:** 45

### 📈 Dashboard Overview
- KPI Cards + Bar Chart: Total Sales by Store
- Line Chart: Total Sales by Year (Peak 2011 - 2.45bn, Drop 2012 - 2.0bn)
- External Factors: Holidays, CPI, Unemployment, Fuel Price

### 🔍 Key Insights
1. High variation between top/bottom stores
2. 2011 peak, 2012 decline ~18%
3. 45 stores tracked consistently
